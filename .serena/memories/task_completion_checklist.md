# タスク完了時のチェックリスト

## コード品質チェック
1. **Biomeチェック実行**
   ```bash
   npm run check:fix
   ```
   - コードフォーマットの自動修正
   - リンティングエラーの修正
   - インポートの自動整理

2. **TypeScript型チェック**
   ```bash
   npm run type-check
   ```
   - 型エラーがないことを確認
   - 厳密な型チェックをパス

## テスト実行
3. **全テスト実行**
   ```bash
   npm run test:run
   ```
   - 全ユニットテストをパス
   - 統合テストをパス
   - システムテストをパス

## ビルド確認（オプション）
4. **本番ビルド**
   ```bash
   npm run build
   ```
   - エラーなしでビルド完了
   - 出力ファイルの確認

## 設計原則の確認
5. **アーキテクチャ準拠**
   - ゲームロジックとグラフィックスの分離維持
   - 設定は `src/settings.ts` で一元管理
   - 型安全性の確保

6. **コード規約準拠**
   - ファイル命名規約（kebab-case）
   - クラス命名規約（PascalCase）
   - インポート整理

## パフォーマンス考慮
7. **メモリ使用量**
   - 不要なオブジェクト生成の回避
   - 適切なクリーンアップ

8. **実行効率**
   - バッチ処理の活用
   - 不要な再計算の回避

## ドキュメント更新
9. **コメント・ドキュメント**
   - 複雑なロジックにコメント追加
   - 型定義の適切な文書化

10. **テストカバレッジ**
    - 新機能のテスト追加
    - エッジケースのテスト確認
