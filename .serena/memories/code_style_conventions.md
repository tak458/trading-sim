# コードスタイル & 規約

## Biome設定
- **インデント**: スペース（タブではない）
- **クォート**: JavaScript/TypeScriptでダブルクォート
- **インポート整理**: 自動インポートソート有効
- **推奨ルール**: Biome推奨リンティングルール全て有効

## ファイル命名規約
- **kebab-case** - ファイル名（例: `village-economy.ts`）
- **PascalCase** - クラス名（例: `VillageEconomyManager`）
- **camelCase** - 関数と変数
- **SCREAMING_SNAKE_CASE** - 定数

## TypeScript設定
- **厳密モード**: 有効
- **ターゲット**: ES2022
- **モジュール**: ESNext
- **noEmit**: true（Viteがビルドを処理）
- **isolatedModules**: true
- **厳密な型チェック**: 有効

## インポート整理
- **絶対インポート**: `@/` エイリアスを使用してsrcディレクトリ
- **グループ化インポート**: 外部ライブラリ、次に内部モジュール
- **自動インポートソート**: Biome設定による

## エディター設定
- **インデントサイズ**: 2スペース
- **インデントスタイル**: スペース
- **最終改行挿入**: true
- **末尾空白削除**: true

## 設計原則
- **関心の分離**: ゲームロジック（ビジネスロジック）とグラフィックス/レンダリングの完全分離
- **設定の一元化**: `src/settings.ts`による型安全性と検証を持つ全設定管理
- **機能的組織**: 技術レイヤーではなく機能/ドメインによるファイルグループ化
- **型安全性**: 包括的なTypeScriptインターフェースと厳密な型チェック
