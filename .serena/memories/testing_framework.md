# テストフレームワーク & 設定

## テスト環境
- **Vitest** - メインテストフレームワーク
- **jsdom** - DOM シミュレーション環境
- **グローバル設定** - テスト関数のグローバル有効化
- **セットアップファイル**: `src/test/setup.ts`

## テスト設定
- **ウォッチモード**: デフォルトで無効（`--run` フラグ使用）
- **パスエイリアス**: `@` が `./src` に解決
- **環境**: jsdom（ブラウザ環境シミュレーション）

## テストコマンド
```bash
# ウォッチモードでテスト実行
npm run test

# 一度だけ実行して終了
npm run test:run

# UIインターフェースでテスト実行
npm run test:ui
```

## テストファイル構造
```
src/test/
├── setup.ts                                    # テスト環境セットアップ
├── *-integration.test.ts                       # 統合テスト
├── *-manager.test.ts                          # マネージャークラステスト
├── system-*.test.ts                           # システムレベルテスト
├── comprehensive-*.test.ts                    # 包括的テスト
└── *.test.ts                                  # 個別ユニットテスト
```

## テストカテゴリ
1. **ユニットテスト** - 個別コンポーネントのテスト
2. **統合テスト** - システム間の連携テスト
3. **システムテスト** - 全体システムの動作テスト
4. **パフォーマンステスト** - 性能要件の確認
5. **エラーハンドリングテスト** - 例外処理の確認

## テストのベストプラクティス
- **AAA パターン**: Arrange, Act, Assert
- **モック使用**: 外部依存の分離
- **エッジケーステスト**: 境界値の確認
- **型安全性**: TypeScriptの型チェック活用
